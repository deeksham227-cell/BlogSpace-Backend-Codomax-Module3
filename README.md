# BlogSpace – Full Stack Blog Application

BlogSpace is a full-stack blog application developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

The application allows users to register, log in, create blogs, view their published blogs, edit blogs, delete blogs, and manage their profile.

## Features

- User Registration
- User Login
- User Authentication
- User Profile
- Logout
- Create and Publish Blogs
- Dashboard
- View Published Blogs
- View Blog Details
- Edit Blogs
- Delete Blogs
- MongoDB Database Integration
- REST API Integration
- Responsive Frontend Interface

## Technologies Used
